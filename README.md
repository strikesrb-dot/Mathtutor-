# Study Coach

Weekend study app: 2 hours of Algebra 1 and 2 hours of Biology, with videos, quizzes, real-life explanations, and fun-fact reward videos. Only focused time counts. A master view shows what got done.

- **Setup:** open `SETUP.html`.
- **Try it now:** open `index.html` (demo mode, no setup needed).
- **For Claude Code:** read `CLAUDE.md`, then `HANDOFF.md`.
