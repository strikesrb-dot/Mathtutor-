Study Coach Setup

About 20–30 minutes on your iPad, done once. You'll end up with a website your brother signs into on his phone or iPad, and a master login you can check from your phone.
Before you start

Try the demo first

Open index.html from the zip, or the GitHub link once Part 1 is done. It runs in demo mode: tap "Open as student" to go through a lesson, then "Open as master" to see the report. Demo data stays on that one device.

Opening index.html straight from the Files app may not work, because Safari blocks some features on local files. If it shows a blank page, do Part 1 first and use the GitHub link.

Part 1 · GitHub

Turn on the website (2 minutes)

The code is already in your repo strikesrb-dot/Mathtutor-.

  1. On github.com, open the Mathtutor- repo → Settings → Pages (left menu).
  2. Under "Build and deployment," set Source to Deploy from a branch. Then set Branch to main and the folder to / (root), and press Save.
  3. Wait 1–2 minutes. Your site is https://strikesrb-dot.github.io/Mathtutor-/. Open it. You should see the demo.
Part 2 · Firebase

Create the database (free Google account)

  1. Go to console.firebase.google.com → Create a project → name it study-coach. Turn off Google Analytics → Create.
  2. Logins: left menu → Build → Authentication → Get started → Email/Password. Turn on the first switch → Save.
  3. Make the two accounts: Authentication → Users tab → Add user.
    • Yours: your email and a password.
    • His: any email (it doesn't have to be real, for example brother@example.com) and a password he can remember.
  4. In the Users list, copy each account's User UID (the long code). Save both in Notes, labeled MASTER (you) and STUDENT (him).
  5. Database: Build → Firestore Database → Create database → pick a US location → Start in production mode → Create.
  6. Lock it down: Firestore → Rules tab. Delete what's there and paste everything from the firestore.rules file. Replace PASTE_MASTER_UID_HERE with your MASTER UID (keep the quotes), then press Publish.
  7. Get the web keys: gear icon ⚙ → Project settings → scroll to "Your apps" → tap the </> (Web) icon → nickname study-coach → Register app (skip Hosting). Copy the firebaseConfig block it shows.
  8. Allow your site: Authentication → Settings → Authorized domains → Add domain → strikesrb-dot.github.io.
Part 3 · Connect them

Paste the keys into the app

Easiest: in Claude Code on the repo, paste the firebaseConfig block and both UIDs, and say:

Put this firebaseConfig into js/config.js (replace the null), set MASTER_UID and STUDENT_UID, set STUDENT_NAME to his name, and put the MASTER UID into firestore.rules. Commit and push.

Or edit it yourself on GitHub: open js/config.js → pencil ✏️ → change export const firebase = null; to your block, fill in the two UIDs → Commit changes.

Part 4 · Devices

Set up his phone and iPad, and your phone

  1. Open https://strikesrb-dot.github.io/Mathtutor-/ in Safari.
  2. Sign in with his email and password on his devices, and yours on your phone.
  3. Share button → Add to Home Screen. Now it opens like an app.
  4. Quick test: on his device, start Block 1 and play the video for a minute. On your phone, the master view should say "Studying right now."
How it holds him to it

What counts and what doesn't

  • Each day has 4 blocks of 50 focused minutes (2 Algebra, 2 Biology), a 10-minute break between them, and a fun-fact video after each subject.
  • Time only counts while the video is playing and the app is on screen. Leaving the app pauses the video and flashes red when he comes back.
  • Every 4–7 minutes a "Still watching?" button appears. If he misses it, the video rewinds to that point and the screen flashes red.
  • He can't skip ahead in a video, and the speed is capped at 1.5×.
  • Quizzes need 90% to pass, and he can retry as many times as he needs. Then he writes a real-life answer in his own words (typed, since pasting is blocked). You can read every answer in Master → Lessons.
  • Every slip shows up as a red flag with the time it happened in your master view.
Changing things later

From your master view → Settings

  • Swap any lesson video (paste a YouTube link).
  • Edit the fun-fact video list.
  • Change the block length or the pass mark.
  • Reset a lesson if you want him to redo it (Master → Lessons → tap the lesson).
